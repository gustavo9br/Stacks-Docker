# Stacks-Docker

Stacks Docker prontas para deploy via Portainer (App Templates), separadas por ambiente:

- [`vps/`](vps/) — stacks para VPS (Docker Swarm + Traefik)
- [`homelab/`](homelab/) — stacks para homelab

## Usando os templates no Portainer

Em **Settings → App Templates → URL**, coloque:

```
https://raw.githubusercontent.com/gustavo9br/Stacks-Docker/refs/heads/main/templates.json
```
